# Realm keys and JWKS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every realm a signing key pair per algorithm, encrypted at rest with a master key from the environment, reachable through a port that hands back a `crypto.Signer`, and published as a JWKS endpoint.

**Architecture:** A new `realm_keys` table across the four dialects, keyed to `realms` by foreign key. `internal/domain/key` holds the aggregate — it derives the `kid` as an RFC 7638 thumbprint and projects the public JWK, and it treats the private material as opaque sealed bytes it cannot read. `internal/infra/sealer` is AES-256-GCM over the master key; `internal/infra/keygen` produces the pairs. `internal/service` declares the three ports it consumes — `Sealer`, `KeyGenerator`, `SignerSource` — and `KeyService` implements the use cases. Realm creation becomes atomic over the realm row and its keys, with generation deliberately outside the transaction. `internal/handler/oidc` serves the JWKS, and `aegisd key` operates all of it without a server running.

**Tech Stack:** Go 1.26, standard library only for the cryptography (`crypto/rsa`, `crypto/ecdsa`, `crypto/aes`, `crypto/cipher`, `crypto/x509`, `encoding/json`, `encoding/base64`), GORM, golang-migrate v4.19.1, chi v5, testcontainers for the engine matrix. **No new module dependencies.**

**Spec:** `docs/superpowers/specs/2026-08-26-realm-keys-and-jwks-design.md`

- Engine floors are unchanged: Postgres 13, MySQL 8.0.16, MariaDB 10.6, SQLite compiled in.
- Migration files: `.up.sql` only, sequential names, **exactly one SQL statement per file**, and the same version numbers present in all four dialect directories. Two existing tests enforce this.

- **On SQLite every text column is `TEXT`.** A `STRICT` table admits only `INT`, `INTEGER`, `REAL`, `TEXT`, `BLOB` and `ANY`; `varchar(64)` there is a DDL error, not a wider `TEXT`.

```go
package configs

import (
	"encoding/base64"
	"errors"
	"fmt"
)

// DevelopmentMasterKey is what the development profile falls back to when no
// key is configured. It is published on purpose: development data is
// disposable, and a documented constant is what keeps `make dev` and Tilt from
// needing setup. Production refuses this exact value, which is what stops the
// convenience from being inherited in silence.
const DevelopmentMasterKey = "ZGV2ZWxvcG1lbnQtb25seS1tYXN0ZXIta2V5LTMyYnk="

// AES-256, so the key is 32 bytes and nothing else is accepted.
const masterKeyBytes = 32

// Crypto carries the secret that encrypts every realm's private signing key.
//
// Both fields are out of YAML, the same rule the database password follows and
// for the same reason: the configuration file is what people commit.
// AEGIS_CRYPTO_MASTER_KEY, or AEGIS_CRYPTO_MASTER_KEY_FILE pointing at a mounted secret,
// are the only routes in.
type Crypto struct {
	MasterKey string `yaml:"-"`

	// Set only while a rewrap is in flight. The sealer opens with whichever key
	// matches a row's recorded kek id, so replicas keep reading every row
	// throughout.
	MasterKeyPrevious string `yaml:"-"`
}

func defaultCrypto() *Crypto {
	// No default value: production has to supply one, and development gets the
	// constant from normalizeForDevelopment rather than from here, so that the
	// production path never sees it.
	return &Crypto{}
}

func (cfg *Crypto) normalizeForDevelopment() {
	if cfg.MasterKey == "" {
		cfg.MasterKey = DevelopmentMasterKey
	}
}

func (cfg *Crypto) Validate(profile Profile) error {
	var errs []error

	if cfg.MasterKey == "" {
		errs = append(errs, errors.New(
			"crypto: master key is required: it encrypts every realm's signing key, and no realm can sign "+
				"without it. Generate one with `openssl rand -base64 32` and set AEGIS_CRYPTO_MASTER_KEY, or "+
				"AEGIS_CRYPTO_MASTER_KEY_FILE pointing at a mounted secret",
		))
	}

	if !profile.IsDev() && cfg.MasterKey == DevelopmentMasterKey {
		errs = append(errs, errors.New(
			"crypto: the development master key is set outside the development profile. It is a published "+
				"constant, so every installation carrying it shares one key: generate a real one with "+
				"`openssl rand -base64 32`",
		))
	}

	errs = append(errs, validateMasterKey("master key", cfg.MasterKey))
	errs = append(errs, validateMasterKey("previous master key", cfg.MasterKeyPrevious))

	return errors.Join(errs...)
}

// Bytes decodes the master key. Validation has already run by the time anything
// calls this, so an error here means the caller skipped it.
func (cfg *Crypto) Bytes() ([]byte, error) {
	return decodeMasterKey("master key", cfg.MasterKey)
}

// PreviousBytes returns nil without an error when no previous key is
// configured, because that is the ordinary case: only a rewrap sets one.
func (cfg *Crypto) PreviousBytes() ([]byte, error) {
	if cfg.MasterKeyPrevious == "" {
		return nil, nil
	}

	return decodeMasterKey("previous master key", cfg.MasterKeyPrevious)
}

func validateMasterKey(name, raw string) error {
	if raw == "" {
		return nil
	}

	_, err := decodeMasterKey(name, raw)

	return err
}

func decodeMasterKey(name, raw string) ([]byte, error) {
	decoded, err := base64.StdEncoding.DecodeString(raw)
	if err != nil {
		// The value itself is never in the message: it is the secret.
		return nil, fmt.Errorf("crypto: %s is not valid base64: %w", name, err)
	}

	if len(decoded) != masterKeyBytes {
		return nil, fmt.Errorf(
			"crypto: %s decodes to %d bytes and has to be exactly %d. Generate one with `openssl rand -base64 32`",
			name, len(decoded), masterKeyBytes,
		)
	}

	return decoded, nil
}
```

```go
// LookupSecret reads a secret from key, or from the file whose path key_FILE
// names. The file form is the shape of a mounted Docker or Kubernetes secret,
// and it is strictly better than the variable: outside /proc/<pid>/environ,
// outside `kubectl describe` on a manifest with an inline value, and not
// inherited by a subprocess.
//
// Both forms set is an error rather than a precedence rule. Which secret is in
// use has to be unambiguous, and a silent winner is how the wrong one gets
// used for months.
func LookupSecret(key string) (string, bool, error) {
	direct, hasDirect := Lookup[string](key)
	path, hasFile := Lookup[string](key + "_FILE")

	switch {
	case hasDirect && hasFile:
		return "", false, fmt.Errorf("envtools: %s and %s_FILE are both set, and only one may be", key, key)
	case hasFile:
		content, err := os.ReadFile(path)
		if err != nil {
			return "", false, fmt.Errorf("envtools: reading %s_FILE at %q: %w", key, path, err)
		}

		// Trailing whitespace is what an editor or `echo` leaves behind, and a
		// secret is compared byte for byte.
		return strings.TrimSpace(string(content)), true, nil
	case hasDirect:
		return direct, true, nil
	}

	return "", false, nil
}
```

```go
func applyCrypto(cfg *configs.Crypto) error {
	if cfg == nil {
		return nil
	}

	var errs []error

	errs = append(errs, secretFromEnv(&cfg.MasterKey, "AEGIS_CRYPTO_MASTER_KEY"))
	errs = append(errs, secretFromEnv(&cfg.MasterKeyPrevious, "AEGIS_CRYPTO_MASTER_KEY_PREVIOUS"))

	return errors.Join(errs...)
}

// secretFromEnv follows fromEnv's rule — only overwrite what the source
// actually declares — with the file form added.
func secretFromEnv(target *string, key string) error {
	value, ok, err := envtools.LookupSecret(key)
	if err != nil {
		return err
	}

	if ok {
		*target = value
	}

	return nil
}
```

```go
// Package key holds a realm's signing keys. It imports nothing beyond the
// standard library and uuid, and it never sees private key material in the
// clear: what it carries is a sealed blob it has no way to open.
package key

import (
	"crypto"
	"crypto/ecdsa"
	"crypto/elliptic"
	"crypto/rsa"
	"fmt"
)

// Algorithm is a JWS "alg" value, and the stored column carries this exact
// string.
type Algorithm string

const (
	AlgorithmRS256 Algorithm = "RS256"
	AlgorithmES256 Algorithm = "ES256"
)

func (a Algorithm) String() string { return string(a) }

func ParseAlgorithm(raw string) (Algorithm, error) {
	switch Algorithm(raw) {
	case AlgorithmRS256:
		return AlgorithmRS256, nil
	case AlgorithmES256:
		return AlgorithmES256, nil
	}

	return "", fmt.Errorf("%w: %q", ErrUnsupportedAlgorithm, raw)
}

// Matches reports whether pub is the kind of key this algorithm signs with. It
// is what keeps an RSA key from being stored as ES256, where every signature
// would carry an alg no verifier would apply to it.
func (a Algorithm) Matches(pub crypto.PublicKey) bool {
	switch a {
	case AlgorithmRS256:
		_, ok := pub.(*rsa.PublicKey)

		return ok
	case AlgorithmES256:
		// The curve is part of the algorithm: ES256 is P-256 and nothing else.
		// ES384 over P-256 would be a different alg with a different digest.
		ec, ok := pub.(*ecdsa.PublicKey)

		return ok && ec.Curve == elliptic.P256()
	}

	return false
}
```

```go
package key

import (
	"crypto"
	"crypto/ecdsa"
	"crypto/elliptic"
	"crypto/rsa"
	"crypto/sha256"
	"encoding/base64"
	"encoding/json"
	"fmt"
	"math/big"
)

// Thumbprint is the RFC 7638 thumbprint of pub: a JWK carrying only the members
// that key family requires, with lexicographic member order and no whitespace,
// hashed with SHA-256 and encoded base64url without padding.
//
// encoding/json produces that canonical form for free — it sorts map keys and
// emits no whitespace — which is exactly what section 3.3 asks for. Building
// the JSON by hand would be a second, divergent implementation of a rule the
// standard library already follows.
func Thumbprint(pub crypto.PublicKey) (string, error) {
	members, err := requiredMembers(pub)
	if err != nil {
		return "", err
	}

	canonical, err := json.Marshal(members)
	if err != nil {
		return "", fmt.Errorf("key: building the canonical jwk: %w", err)
	}

	sum := sha256.Sum256(canonical)

	return base64.RawURLEncoding.EncodeToString(sum[:]), nil
}

// requiredMembers is the single source both the thumbprint and the published
// JWK read from. Two constructions of the same object are the pair that
// eventually disagree, and disagreeing here means a kid that does not identify
// the key it is attached to.
func requiredMembers(pub crypto.PublicKey) (map[string]string, error) {
	switch typed := pub.(type) {
	case *rsa.PublicKey:
		return map[string]string{
			"e":   encodeUnsigned(big.NewInt(int64(typed.E))),
			"kty": "RSA",
			"n":   encodeUnsigned(typed.N),
		}, nil
	case *ecdsa.PublicKey:
		if typed.Curve != elliptic.P256() {
			return nil, fmt.Errorf("key: %s is not a supported curve", typed.Curve.Params().Name)
		}

		size := coordinateSize(typed.Curve)

		return map[string]string{
			"crv": "P-256",
			"kty": "EC",
			"x":   encodeCoordinate(typed.X, size),
			"y":   encodeCoordinate(typed.Y, size),
		}, nil
	}

	return nil, fmt.Errorf("key: %T is not a supported public key", pub)
}

// encodeUnsigned is the minimal big-endian form JWA requires for RSA n and e:
// no leading zero byte, which is what big.Int.Bytes already produces.
func encodeUnsigned(value *big.Int) string {
	return base64.RawURLEncoding.EncodeToString(value.Bytes())
}

// encodeCoordinate is fixed-width, left-padded to the curve's field size — the
// opposite rule from RSA above. big.Int.Bytes would trim a leading zero byte,
// producing a coordinate one byte short: a JWK that looks right and verifies
// nothing. FillBytes pads instead.
func encodeCoordinate(value *big.Int, size int) string {
	padded := make([]byte, size)
	value.FillBytes(padded)

	return base64.RawURLEncoding.EncodeToString(padded)
}

func coordinateSize(curve elliptic.Curve) int {
	return (curve.Params().BitSize + 7) / 8
}
```

```go
		N:   members["n"],
		E:   members["e"],
```

```go
package key

import (
	"crypto"
	"crypto/x509"
	"errors"
	"fmt"
	"time"

	"github.com/google/uuid"
)

// Key is a realm's signing key. Private fields with accessors and no setter for
// id, realmID, kid, purpose or algorithm: the identity of a key is immutable by
// compiler rather than by memory, the same shape realm.Realm uses for its
// issuer.
//
// The private material is here only as `sealed`, and this package has no way to
// open it: the cipher and the master key belong to infrastructure. That is what
// keeps the domain testable without a key, and what leaves room for a KMS,
// which would never hand private material over at all.
type Key struct {
	id        uuid.UUID
	realmID   uuid.UUID
	kid       string
	purpose   Purpose
	algorithm Algorithm
	status    Status
	publicKey crypto.PublicKey
	sealed    []byte
	kekID     string
	createdAt time.Time
	updatedAt time.Time
}

// New is birth: it generates the identifier, derives the kid from the public
// key, and stamps both timestamps to the same UTC instant.
//
// A key is born active, and that is the only way a key ever becomes active.
// There is no Activate, which is what makes an insert the single writer of
// active_marker.
func New(
	realmID uuid.UUID,
	purpose Purpose,
	algorithm Algorithm,
	publicKey crypto.PublicKey,
	sealed []byte,
	kekID string,
) (*Key, error) {
	if realmID == uuid.Nil {
		return nil, errors.New("key: a key needs a realm")
	}

	if _, err := ParsePurpose(purpose.String()); err != nil {
		return nil, err
	}

	if _, err := ParseAlgorithm(algorithm.String()); err != nil {
		return nil, err
	}

	if !algorithm.Matches(publicKey) {
		return nil, fmt.Errorf("key: %T is not a %s key", publicKey, algorithm)
	}

	if len(sealed) == 0 {
		return nil, errors.New("key: the sealed private material is empty")
	}

	if kekID == "" {
		return nil, errors.New("key: the sealed material has no kek id, so nothing could open it")
	}

	kid, err := Thumbprint(publicKey)
	if err != nil {
		return nil, err
	}

	// NewV7 reads the clock and the entropy source; uuid.Must would turn a
	// transient failure into a panic inside a request.
	id, err := uuid.NewV7()
	if err != nil {
		return nil, fmt.Errorf("key: generating an identifier: %w", err)
	}

	now := nowUTC()

	return &Key{
		id:        id,
		realmID:   realmID,
		kid:       kid,
		purpose:   purpose,
		algorithm: algorithm,
		status:    StatusActive,
		publicKey: publicKey,
		sealed:    sealed,
		kekID:     kekID,
		createdAt: now,
		updatedAt: now,
	}, nil
}

// Rehydrate is the repository's door back in. It takes the stored kid as given
// rather than recomputing it: an identity recomputed on every read is how a
// stored value and a derived value drift apart with no symptom, which is the
// same reason realm.Rehydrate takes the stored issuer.
//
// It validates everything else, because a customer's DBA writes here directly.
func Rehydrate(
	id uuid.UUID,
	realmID uuid.UUID,
	kid string,
	purpose Purpose,
	algorithm Algorithm,
	status Status,
	publicKeyDER []byte,
	sealed []byte,
	kekID string,
	createdAt time.Time,
	updatedAt time.Time,
) (*Key, error) {
	if id == uuid.Nil || realmID == uuid.Nil {
		return nil, errors.New("key: a stored key needs an id and a realm")
	}

	if kid == "" {
		return nil, errors.New("key: a stored key needs a kid")
	}

	if _, err := ParsePurpose(purpose.String()); err != nil {
		return nil, err
	}

	if _, err := ParseAlgorithm(algorithm.String()); err != nil {
		return nil, err
	}

	if _, err := ParseStatus(status.String()); err != nil {
		return nil, err
	}

	publicKey, err := x509.ParsePKIXPublicKey(publicKeyDER)
	if err != nil {
		return nil, fmt.Errorf("key: reading the stored public key: %w", err)
	}

	if !algorithm.Matches(publicKey) {
		return nil, fmt.Errorf("key: the stored public key is not a %s key", algorithm)
	}

	if len(sealed) == 0 || kekID == "" {
		return nil, errors.New("key: the stored private material is incomplete")
	}

	return &Key{
		id:        id,
		realmID:   realmID,
		kid:       kid,
		purpose:   purpose,
		algorithm: algorithm,
		status:    status,
		publicKey: publicKey,
		sealed:    sealed,
		kekID:     kekID,
		createdAt: createdAt.UTC(),
		updatedAt: updatedAt.UTC(),
	}, nil
}

func (k *Key) ID() uuid.UUID          { return k.id }
func (k *Key) RealmID() uuid.UUID     { return k.realmID }
func (k *Key) KID() string            { return k.kid }
func (k *Key) Purpose() Purpose       { return k.purpose }
func (k *Key) Algorithm() Algorithm   { return k.algorithm }
func (k *Key) Status() Status         { return k.status }
func (k *Key) PublicKey() crypto.PublicKey { return k.publicKey }
func (k *Key) KEKID() string          { return k.kekID }
func (k *Key) CreatedAt() time.Time   { return k.createdAt }
func (k *Key) UpdatedAt() time.Time   { return k.updatedAt }
func (k *Key) Published() bool        { return k.status.Published() }

// Ref is the pair a JWS header carries.
func (k *Key) Ref() Ref { return Ref{KID: k.kid, Algorithm: k.algorithm} }

// Sealed returns a copy. The slice is the ciphertext of a private key, and a
// caller holding the backing array could change what the aggregate believes it
// has.
func (k *Key) Sealed() []byte {
	out := make([]byte, len(k.sealed))
	copy(out, k.sealed)

	return out
}

// PublicKeyDER marshals rather than storing a second copy: DER from
// MarshalPKIXPublicKey is deterministic, so one parsed key is the single source
// of truth and there is no pair to drift.
func (k *Key) PublicKeyDER() ([]byte, error) {
	der, err := x509.MarshalPKIXPublicKey(k.publicKey)
	if err != nil {
		return nil, fmt.Errorf("key: marshalling the public key: %w", err)
	}

	return der, nil
}

// Rewrapped records that the same private key is now sealed under another kek.
// The plaintext never enters this package: the caller opened and resealed it.
func (k *Key) Rewrapped(sealed []byte, kekID string) error {
	if len(sealed) == 0 || kekID == "" {
		return errors.New("key: a rewrap needs sealed material and a kek id")
	}

	k.sealed = sealed
	k.kekID = kekID
	k.touch()

	return nil
}

func (k *Key) Deactivate() error {
	if k.status != StatusActive {
		return fmt.Errorf("%w: %s cannot be deactivated", ErrInvalidTransition, k.status)
	}

	k.status = StatusPassive
	k.touch()

	return nil
}

func (k *Key) Disable() error {
	// An active key is refused on purpose: disabling it would leave the realm
	// with nothing able to sign. Revoking a compromised key is a rotation and
	// then a disable, which is the correct order anyway — the replacement
	// exists before the old key stops being published.
	if k.status != StatusPassive {
		return fmt.Errorf("%w: %s cannot be disabled; rotate first", ErrInvalidTransition, k.status)
	}

	k.status = StatusDisabled
	k.touch()

	return nil
}

func (k *Key) Enable() error {
	if k.status != StatusDisabled {
		return fmt.Errorf("%w: %s cannot be enabled", ErrInvalidTransition, k.status)
	}

	// Passive and not active: putting a key back into service is a rotation.
	k.status = StatusPassive
	k.touch()

	return nil
}

func (k *Key) touch() { k.updatedAt = nowUTC() }

// Microsecond precision, matching what the repository stores: a value the
// database cannot hold would come back different from what was written.
func nowUTC() time.Time { return time.Now().UTC().Truncate(time.Microsecond) }
```

```go
// Package sealer encrypts private key material with the installation's master
// key. It satisfies service.Sealer without importing it, which is what leaves
// the interface free to be satisfied by something else later.
package sealer

import (
	"crypto/aes"
	"crypto/cipher"
	"crypto/rand"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
)

// kekIDDomain separates this digest from any other use of the same material,
// so a recorded id is not a bare hash of the secret.
const kekIDDomain = "aegis:kek:v1"

// kekIDBytes is how much of the digest becomes the id. Sixteen bytes is far
// past any collision concern for a value that distinguishes at most a handful
// of keys per installation.
const kekIDBytes = 16

type ring struct {
	id   string
	aead cipher.AEAD
}

// Sealer seals with the current key always, and opens with whichever key a
// row's recorded kek id names. Holding both is what lets `aegisd key rewrap`
// run while the service is serving traffic.
type Sealer struct {
	current  ring
	previous *ring
}

// New takes raw 32-byte keys. previous is nil in the ordinary case; only a
// rewrap configures one.
func New(current, previous []byte) (*Sealer, error) {
	currentRing, err := newRing(current)
	if err != nil {
		return nil, err
	}

	built := &Sealer{current: currentRing}

	if len(previous) == 0 {
		return built, nil
	}

	previousRing, err := newRing(previous)
	if err != nil {
		return nil, err
	}

	if previousRing.id == currentRing.id {
		return nil, errors.New("sealer: the previous master key is the current one, so a rewrap would do nothing")
	}

	built.previous = &previousRing

	return built, nil
}

func newRing(material []byte) (ring, error) {
	// aes.NewCipher is what rejects a key that is not 16, 24 or 32 bytes; the
	// configuration section has already required exactly 32.
	block, err := aes.NewCipher(material)
	if err != nil {
		return ring{}, fmt.Errorf("sealer: %w", err)
	}

	aead, err := cipher.NewGCM(block)
	if err != nil {
		return ring{}, fmt.Errorf("sealer: %w", err)
	}

	return ring{id: KEKID(material), aead: aead}, nil
}

// KEKID derives the identifier a row records for the key that sealed it.
// Derived rather than configured: a label chosen by an operator can be left
// behind when the material changes, and then every row claims to be openable
// by a key that does not open it.
func KEKID(material []byte) string {
	sum := sha256.Sum256(append([]byte(kekIDDomain), material...))

	return hex.EncodeToString(sum[:kekIDBytes])
}

// CurrentKEKID is what a caller records beside freshly sealed material.
func (s *Sealer) CurrentKEKID() string { return s.current.id }

// Seal returns nonce ‖ ciphertext ‖ tag, and the id of the key that sealed it.
//
// The nonce is random rather than a counter: the birthday bound is around 2^32
// seals under one key, and this table sees a handful of writes per realm per
// year, while a counter would need state that survives restarts and replicas.
func (s *Sealer) Seal(plaintext, aad []byte) ([]byte, string, error) {
	nonce := make([]byte, s.current.aead.NonceSize())
	if _, err := rand.Read(nonce); err != nil {
		return nil, "", fmt.Errorf("sealer: reading a nonce: %w", err)
	}

	// Seal appends to its first argument, so the nonce becomes the prefix of
	// the blob that Open splits back off.
	return s.current.aead.Seal(nonce, nonce, plaintext, aad), s.current.id, nil
}

func (s *Sealer) Open(sealed, aad []byte, kekID string) ([]byte, error) {
	chosen, err := s.ring(kekID)
	if err != nil {
		return nil, err
	}

	size := chosen.aead.NonceSize()
	if len(sealed) < size {
		return nil, errors.New("sealer: the sealed material is shorter than a nonce")
	}

	plaintext, err := chosen.aead.Open(nil, sealed[:size], sealed[size:], aad)
	if err != nil {
		// Never more specific than this. A wrong key, a row belonging to
		// another realm and a modified ciphertext are one failure to GCM, and
		// distinguishing them would report which guess was closer.
		return nil, errors.New("sealer: the sealed material did not open")
	}

	return plaintext, nil
}

func (s *Sealer) ring(kekID string) (ring, error) {
	switch {
	case kekID == s.current.id:
		return s.current, nil
	case s.previous != nil && kekID == s.previous.id:
		return *s.previous, nil
	}

	return ring{}, fmt.Errorf(
		"sealer: no master key with id %q is loaded. If this row predates a master key change, "+
			"set AEGIS_CRYPTO_MASTER_KEY_PREVIOUS and run `aegisd key rewrap`",
		kekID,
	)
}
```

```go
// Package keygen produces the key pairs a realm signs with. It satisfies
// service.KeyGenerator without importing it.
//
// It exists as a package of its own, rather than as a call into crypto/rsa
// inside the service, for one reason that is not architectural: without it
// every service unit test pays a real RSA-2048 generation.
package keygen

import (
	"crypto"
	"crypto/ecdsa"
	"crypto/elliptic"
	"crypto/rand"
	"crypto/rsa"
	"crypto/x509"
	"fmt"

	"github.com/rootless-dev/aegis/internal/domain/key"
)

// Not configurable in this slice. 2048 is the floor every current guideline
// agrees on and what Keycloak generates by default; a configurable size needs
// somewhere to configure it, which is the admin API.
const rsaBits = 2048

type Generator struct{}

func New() Generator { return Generator{} }

// Generate returns the signer and the PKCS#8 DER of its private half. The
// caller seals the second; the public half is reachable from the signer, and
// the aggregate marshals it, so returning it here would be a second producer
// of the same bytes.
func (Generator) Generate(algorithm key.Algorithm) (crypto.Signer, []byte, error) {
	var signer crypto.Signer

	switch algorithm {
	case key.AlgorithmRS256:
		private, err := rsa.GenerateKey(rand.Reader, rsaBits)
		if err != nil {
			return nil, nil, fmt.Errorf("keygen: generating an rsa key: %w", err)
		}

		signer = private
	case key.AlgorithmES256:
		private, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
		if err != nil {
			return nil, nil, fmt.Errorf("keygen: generating an ec key: %w", err)
		}

		signer = private
	default:
		return nil, nil, fmt.Errorf("%w: %q", key.ErrUnsupportedAlgorithm, algorithm)
	}

	pkcs8, err := x509.MarshalPKCS8PrivateKey(signer)
	if err != nil {
		return nil, nil, fmt.Errorf("keygen: marshalling the private key: %w", err)
	}

	return signer, pkcs8, nil
}
```

```go
// implementation in internal/infra/sealer does not know this interface exists,
// which is what leaves room for something else to satisfy it.
type Sealer interface {
	// Seal reports the id of the key it sealed with, which the row records so
	// that a later process knows what opens it.
	Seal(plaintext, aad []byte) (sealed []byte, kekID string, err error)

	// Open takes the row's recorded kekID rather than guessing, so a rewrap in
	// flight can be read by a process holding both keys.
	Open(sealed, aad []byte, kekID string) ([]byte, error)

	CurrentKEKID() string
}

// KeyGenerator produces a key pair and the PKCS#8 encoding of its private half.
// It is a port for a reason that is not architectural: without it every unit
// test here pays a real RSA-2048 generation.
type KeyGenerator interface {

// produces, like CertificateSource, and not `Signer`, which would collide with
// crypto.Signer in this very file.
//
// Nothing in this slice consumes it. It exists so the token service in slice 4
// depends on an interface rather than on *KeyService, and so a KMS can replace
// the implementation whole: a KMS never returns private material, so "open the
// seal and parse" has no analogue there, while "give me something that can sign
// for this realm" does.
type SignerSource interface {

}

	// Translates uq_realm_keys_active into key.ErrActiveKeyExists and
	// uq_realm_keys_kid into key.ErrKIDTaken.
	Create(ctx context.Context, k *key.Key) error

	// Returns key.ErrNoActiveKey when the realm has none for that algorithm,
	// which several callers treat as ordinary rather than as a failure.
	FindActive(ctx context.Context, realmID uuid.UUID, purpose key.Purpose, algorithm key.Algorithm) (*key.Key, error)

	// Returns key.ErrNotFound.
	FindByKID(ctx context.Context, realmID uuid.UUID, kid string) (*key.Key, error)

	// Ordered id descending, which is deterministic on all four engines and
	// chronological because the id is a UUIDv7. An empty statuses slice means
	// every status.
	ListByRealm(ctx context.Context, realmID uuid.UUID, statuses []key.Status) ([]*key.Key, error)

	// Writes status, active_marker and updated_at, and no other column.
	Update(ctx context.Context, k *key.Key) error

	// Writes private_key, kek_id and updated_at, and no other column. Separate
	// from Update because sealed material is immutable outside a rewrap, the
	// same reasoning that keeps Reissue separate on realms.
	Rewrap(ctx context.Context, k *key.Key) error

	// Rows not sealed under kekID, across every realm, capped at limit. No
	// cursor: a row leaves this set as soon as it is rewrapped, so asking
	// again from the start both terminates and resumes.
	ListStaleKEK(ctx context.Context, kekID string, limit int) ([]*key.Key, error)
```

```go
package service

import (
	"context"
	"crypto"
	"crypto/x509"
	"errors"
	"fmt"

	"github.com/google/uuid"
	"github.com/rootless-dev/aegis/internal/domain/key"
)

// DefaultAlgorithms is what a realm is provisioned with. RS256 is what every
// OIDC client library supports without exception; ES256 is there because the
// second algorithm has to be exercised by real code from the start, or the
// seam that admits it is only believed to work.
var DefaultAlgorithms = []key.Algorithm{key.AlgorithmRS256, key.AlgorithmES256}

// defaultRewrapBatch is how many rows a rewrap reads at a time. Small, because
// each row holds a decrypted private key in memory for the length of one write.
const defaultRewrapBatch = 50

type KeyService struct {
	store     Store
	sealer    Sealer
	generator KeyGenerator
}

func NewKeyService(store Store, sealer Sealer, generator KeyGenerator) *KeyService {
	return &KeyService{store: store, sealer: sealer, generator: generator}
}

// Prepare generates and seals, and deliberately touches no database and takes
// no context: generating RSA-2048 costs hundreds of milliseconds, and holding a
// transaction open across it is what this split exists to prevent. The caller
// persists the result inside its own transaction.
func (s *KeyService) Prepare(realmID uuid.UUID, algorithms ...key.Algorithm) ([]*key.Key, error) {
	if len(algorithms) == 0 {
		algorithms = DefaultAlgorithms
	}

	prepared := make([]*key.Key, 0, len(algorithms))

	for _, algorithm := range algorithms {
		signer, pkcs8, err := s.generator.Generate(algorithm)
		if err != nil {
			return nil, err
		}

		// The thumbprint is computed here rather than read off the aggregate,
		// because the aad needs the kid and the aggregate needs the sealed
		// blob: the kid comes from the public key, so it is the one of the
		// three that exists first.
		kid, err := key.Thumbprint(signer.Public())
		if err != nil {
			return nil, err
		}

		sealed, kekID, err := s.sealer.Seal(pkcs8, keyAAD(realmID, kid))
		if err != nil {
			return nil, fmt.Errorf("service: sealing a private key: %w", err)
		}

		built, err := key.New(realmID, key.PurposeSignature, algorithm, signer.Public(), sealed, kekID)
		if err != nil {
			return nil, err
		}

		prepared = append(prepared, built)
	}

	return prepared, nil
}

// persist writes prepared keys inside a transaction the caller owns. Unexported
// because the two callers are in this package: RealmService.Create and
// EnsureKeys.
func (s *KeyService) persist(ctx context.Context, st Store, keys []*key.Key) error {
	for _, built := range keys {
		if err := st.Keys().Create(ctx, built); err != nil {
			return err
		}
	}

	return nil
}

// EnsureKeys gives a realm an active key for each algorithm it lacks, and
// touches nothing else — it never rotates, never disables, and never
// reconciles a key that already exists. It is what the boot seed calls.
//
// The read comes first because without it every boot generates two key pairs
// only to discard them.
func (s *KeyService) EnsureKeys(
	ctx context.Context, realmID uuid.UUID, algorithms ...key.Algorithm,
) ([]*key.Key, error) {
	if len(algorithms) == 0 {
		algorithms = DefaultAlgorithms
	}

	missing := make([]key.Algorithm, 0, len(algorithms))

	for _, algorithm := range algorithms {
		_, err := s.store.Keys().FindActive(ctx, realmID, key.PurposeSignature, algorithm)

		switch {
		case err == nil:
			continue
		case errors.Is(err, key.ErrNoActiveKey):
			missing = append(missing, algorithm)
		default:
			return nil, err
		}
	}

	if len(missing) == 0 {
		return s.Published(ctx, realmID)
	}

	prepared, err := s.Prepare(realmID, missing...)
	if err != nil {
		return nil, err
	}

	err = s.store.InTx(ctx, func(tx Store) error { return s.persist(ctx, tx, prepared) })

	// Another replica seeded between the read and the insert: migration holds a
	// session lock, the seed does not. uq_realm_keys_active is what resolves
	// it, and the replica that lost adopts the row that won rather than
	// failing the boot.
	if err != nil && !errors.Is(err, key.ErrActiveKeyExists) {
		return nil, err
	}

	return s.Published(ctx, realmID)
}

// Rotate makes a new key active and moves the outgoing one to passive, so every
// token already signed stays verifiable until it expires.
//
// A realm with no active key for the algorithm is not an error: rotation is the
// recovery path after a key was disabled by mistake.
func (s *KeyService) Rotate(
	ctx context.Context, realmID uuid.UUID, algorithm key.Algorithm,
) (*key.Key, error) {
	prepared, err := s.Prepare(realmID, algorithm)
	if err != nil {
		return nil, err
	}

	replacement := prepared[0]

	err = s.store.InTx(ctx, func(tx Store) error {
		outgoing, findErr := tx.Keys().FindActive(ctx, realmID, key.PurposeSignature, algorithm)

		switch {
		case findErr == nil:
			if deactivateErr := outgoing.Deactivate(); deactivateErr != nil {
				return deactivateErr
			}

			if updateErr := tx.Keys().Update(ctx, outgoing); updateErr != nil {
				return updateErr
			}
		case !errors.Is(findErr, key.ErrNoActiveKey):
			return findErr
		}

		// Two concurrent rotations collide here, and one loses. That is the
		// correct outcome: the alternative is two active keys.
		return tx.Keys().Create(ctx, replacement)
	})
	if err != nil {
		return nil, err
	}

	return replacement, nil
}

// Disable takes a key out of the JWKS. It refuses an active key, because the
// realm would be left with nothing able to sign.
func (s *KeyService) Disable(ctx context.Context, realmID uuid.UUID, kid string) error {
	return s.mutate(ctx, realmID, kid, func(k *key.Key) error { return k.Disable() })
}

// Enable puts a disabled key back into the JWKS as passive. Making it active
// again is a rotation.
func (s *KeyService) Enable(ctx context.Context, realmID uuid.UUID, kid string) error {
	return s.mutate(ctx, realmID, kid, func(k *key.Key) error { return k.Enable() })
}

// List is every key of the realm, disabled ones included: whoever is asking has
// to see what there is to enable.
func (s *KeyService) List(ctx context.Context, realmID uuid.UUID) ([]*key.Key, error) {
	return s.store.Keys().ListByRealm(ctx, realmID, nil)
}

// Published is what the JWKS serves: active and passive, never disabled.
func (s *KeyService) Published(ctx context.Context, realmID uuid.UUID) ([]*key.Key, error) {
	return s.store.Keys().ListByRealm(ctx, realmID, []key.Status{key.StatusActive, key.StatusPassive})
}

// SignerFor satisfies SignerSource. No cache: what costs here is the round trip,
// and nothing signs per request until slice 4, where a cache can be measured
// instead of guessed — and where the staleness a rotation on another replica
// causes has to be answered.
func (s *KeyService) SignerFor(
	ctx context.Context, realmID uuid.UUID, algorithm key.Algorithm,
) (crypto.Signer, key.Ref, error) {
	found, err := s.store.Keys().FindActive(ctx, realmID, key.PurposeSignature, algorithm)
	if err != nil {
		return nil, key.Ref{}, err
	}

	pkcs8, err := s.sealer.Open(found.Sealed(), keyAAD(realmID, found.KID()), found.KEKID())
	if err != nil {
		return nil, key.Ref{}, fmt.Errorf("service: opening the private key of %s: %w", found.KID(), err)
	}

	parsed, err := x509.ParsePKCS8PrivateKey(pkcs8)
	if err != nil {
		return nil, key.Ref{}, fmt.Errorf("service: reading the private key of %s: %w", found.KID(), err)
	}

	signer, ok := parsed.(crypto.Signer)
	if !ok {
		return nil, key.Ref{}, fmt.Errorf("service: the stored %T cannot sign", parsed)
	}

	return signer, found.Ref(), nil
}

// Rewrap moves every row to the current master key, one row at a time and with
// no transaction spanning them. That is the point of the recorded kek id: each
// row states which key opens it, so an interrupted rewrap leaves a consistent
// database, running the command again continues where it stopped, and running
// it after it finished does nothing.
func (s *KeyService) Rewrap(ctx context.Context, batch int) (int, error) {
	if batch <= 0 {
		batch = defaultRewrapBatch
	}

	target := s.sealer.CurrentKEKID()
	moved := 0

	for {
		// No cursor: a row leaves this set the moment it is rewrapped, so
		// asking again from the start both terminates and resumes.
		stale, err := s.store.Keys().ListStaleKEK(ctx, target, batch)
		if err != nil {
			return moved, err
		}

		if len(stale) == 0 {
			return moved, nil
		}

		for _, found := range stale {
			if err := s.rewrapOne(ctx, found); err != nil {
				return moved, err
			}

			moved++
		}
	}
}

func (s *KeyService) rewrapOne(ctx context.Context, found *key.Key) error {
	aad := keyAAD(found.RealmID(), found.KID())

	pkcs8, err := s.sealer.Open(found.Sealed(), aad, found.KEKID())
	if err != nil {
		return fmt.Errorf(
			"service: rewrapping key %s of realm %s: %w", found.KID(), found.RealmID(), err,
		)
	}

	sealed, kekID, err := s.sealer.Seal(pkcs8, aad)
	if err != nil {
		return err
	}

	if err := found.Rewrapped(sealed, kekID); err != nil {
		return err
	}

	return s.store.Keys().Rewrap(ctx, found)
}

func (s *KeyService) mutate(
	ctx context.Context, realmID uuid.UUID, kid string, apply func(*key.Key) error,
) error {
	return s.store.InTx(ctx, func(tx Store) error {
		found, err := tx.Keys().FindByKID(ctx, realmID, kid)
		if err != nil {
			return err
		}

		if err := apply(found); err != nil {
			return err
		}

		return tx.Keys().Update(ctx, found)
	})
}

// keyAAD binds a sealed blob to the realm and the key it belongs to, so a row
// copied into another realm does not open. In a product whose worst failure is
// leakage across the tenancy boundary, that boundary is worth holding in the
// cipher and not only in a WHERE clause.
//
// It is realm_id and kid rather than realm_id and id because key.New generates
// the id and needs the sealed blob to construct the aggregate, while the kid
// derives from the public key and therefore exists before both. It binds just
// as tightly, being a hash of the very key being sealed.
func keyAAD(realmID uuid.UUID, kid string) []byte {
	return []byte(realmID.String() + "|" + kid)
}
```

```go
package repository

import (
	"errors"
	"strings"

	"github.com/rootless-dev/aegis/internal/domain/key"
	"github.com/rootless-dev/aegis/internal/domain/realm"
	"gorm.io/gorm"
)

// translate keeps gorm.ErrRecordNotFound and every driver's unique-violation
// text inside this package.
//
// The not-found error is a parameter because there is more than one aggregate
// now, and because one query wants a different one from the other two:
// FindActive turning up empty is key.ErrNoActiveKey, which several callers
// treat as ordinary rather than as a failure.
func translate(err error, notFound error) error {
	if err == nil {
		return nil
	}

	if errors.Is(err, gorm.ErrRecordNotFound) {
		return notFound
	}

	// Keyed off the constraint name: no engine exposes the violation as a typed
	// value the four share.
	message := strings.ToLower(err.Error())

	switch {
	case strings.Contains(message, "uq_realms_slug"):
		return realm.ErrSlugTaken
	case strings.Contains(message, "uq_realms_issuer"):
		return realm.ErrIssuerTaken
	case strings.Contains(message, "uq_realm_keys_kid"):
		return key.ErrKIDTaken
	case strings.Contains(message, "uq_realm_keys_active"):
		return key.ErrActiveKeyExists
	}

	// SQLite names the columns, not the constraint. Anchored on the prefix and
	// not the column alone: NOT NULL and CHECK violations name it too.
	//
	// Both key indexes lead with realm_id, so the distinctive column is what
	// separates them.
	if strings.Contains(message, "unique constraint failed: ") {
		switch {
		case strings.Contains(message, "realms.slug"):
			return realm.ErrSlugTaken
		case strings.Contains(message, "realms.issuer"):
			return realm.ErrIssuerTaken
		case strings.Contains(message, "realm_keys.active_marker"):
			return key.ErrActiveKeyExists
		case strings.Contains(message, "realm_keys.kid"):
			return key.ErrKIDTaken
		}
	}

	return err
}
```

```go
package repository

import (
	"encoding/base64"

	"github.com/google/uuid"
	"github.com/rootless-dev/aegis/internal/domain/key"
)

// activeMarker is what makes "one active key per realm, purpose and algorithm"
// a rule the database keeps. A partial index is the natural way to say it, and
// MySQL and MariaDB have none — so the rule moves into a column that is NULL on
// every row it does not apply to, and NULLs do not collide in a unique index on
// any of the four engines.
const activeMarker = "y"

// No gorm type tag on any field: GORM never generates DDL here, so a tag would
// be a second description of a column the migrations already define.
type realmKeyRecord struct {
	ID        string `gorm:"column:id;primaryKey"`
	RealmID   string `gorm:"column:realm_id"`
	KID       string `gorm:"column:kid"`
	Purpose   string `gorm:"column:purpose"`
	Algorithm string `gorm:"column:algorithm"`
	Status    string `gorm:"column:status"`

	// A pointer, because the column is NULL for every row that is not active
	// and an empty string would collide in the unique index exactly as a
	// duplicate would.
	ActiveMarker *string `gorm:"column:active_marker"`

	PublicKey  string    `gorm:"column:public_key"`
	PrivateKey string    `gorm:"column:private_key"`
	KEKID      string    `gorm:"column:kek_id"`
	CreatedAt  Timestamp `gorm:"column:created_at"`
	UpdatedAt  Timestamp `gorm:"column:updated_at"`
}

func (realmKeyRecord) TableName() string { return "realm_keys" }

func keyFromDomain(k *key.Key) (realmKeyRecord, error) {
	publicKey, err := k.PublicKeyDER()
	if err != nil {
		return realmKeyRecord{}, err
	}

	return realmKeyRecord{
		// Canonical 36-character form on every dialect, Postgres included,
		// where the driver casts it to uuid.
		ID:        k.ID().String(),
		RealmID:   k.RealmID().String(),
		KID:       k.KID(),
		Purpose:   k.Purpose().String(),
		Algorithm: k.Algorithm().String(),
		Status:    k.Status().String(),

		ActiveMarker: markerFor(k.Status()),

		// Base64 rather than a binary column: a readable dump, no bytea hex
		// escaping, and no per-driver difference in how a blob round trips.
		PublicKey:  base64.StdEncoding.EncodeToString(publicKey),
		PrivateKey: base64.StdEncoding.EncodeToString(k.Sealed()),
		KEKID:      k.KEKID(),
		CreatedAt:  Timestamp(k.CreatedAt()),
		UpdatedAt:  Timestamp(k.UpdatedAt()),
	}, nil
}

// markerFor derives the column rather than reading it off the aggregate. It is
// not a fact about a key, it is the mechanism behind one rule, and nothing
// outside this file should be able to set it.
func markerFor(status key.Status) *string {
	if status != key.StatusActive {
		return nil
	}

	marker := activeMarker

	return &marker
}

// Through Rehydrate, which validates: a customer's DBA writes here directly.
func (rec realmKeyRecord) toDomain() (*key.Key, error) {
	id, err := uuid.Parse(rec.ID)
	if err != nil {
		return nil, err
	}

	realmID, err := uuid.Parse(rec.RealmID)
	if err != nil {
		return nil, err
	}

	purpose, err := key.ParsePurpose(rec.Purpose)
	if err != nil {
		return nil, err
	}

	algorithm, err := key.ParseAlgorithm(rec.Algorithm)
	if err != nil {
		return nil, err
	}

	status, err := key.ParseStatus(rec.Status)
	if err != nil {
		return nil, err
	}

	publicKey, err := base64.StdEncoding.DecodeString(rec.PublicKey)
	if err != nil {
		return nil, err
	}

	sealed, err := base64.StdEncoding.DecodeString(rec.PrivateKey)
	if err != nil {
		return nil, err
	}

	return key.Rehydrate(
		id, realmID, rec.KID, purpose, algorithm, status,
		publicKey, sealed, rec.KEKID,
		rec.CreatedAt.Time(), rec.UpdatedAt.Time(),
	)
}
```

```go
package repository

import (
	"context"

	"github.com/google/uuid"
	"github.com/rootless-dev/aegis/internal/domain/key"
	"gorm.io/gorm"
)

type realmKeyRepository struct {
	db *gorm.DB
}

func (r realmKeyRepository) Create(ctx context.Context, k *key.Key) error {
	record, err := keyFromDomain(k)
	if err != nil {
		return err
	}

	return translate(r.db.WithContext(ctx).Create(&record).Error, key.ErrNotFound)
}

func (r realmKeyRepository) FindActive(
	ctx context.Context, realmID uuid.UUID, purpose key.Purpose, algorithm key.Algorithm,
) (*key.Key, error) {
	var record realmKeyRecord

	err := r.db.WithContext(ctx).
		Where(
			"realm_id = ? AND purpose = ? AND algorithm = ? AND status = ?",
			realmID.String(), purpose.String(), algorithm.String(), key.StatusActive.String(),
		).
		Take(&record).Error
	if err != nil {
		// Its own not-found error: an absent active key is ordinary for
		// Rotate and EnsureKeys, and only SignerFor treats it as a failure.
		return nil, translate(err, key.ErrNoActiveKey)
	}

	return record.toDomain()
}

func (r realmKeyRepository) FindByKID(
	ctx context.Context, realmID uuid.UUID, kid string,
) (*key.Key, error) {
	var record realmKeyRecord

	err := r.db.WithContext(ctx).
		Where("realm_id = ? AND kid = ?", realmID.String(), kid).
		Take(&record).Error
	if err != nil {
		return nil, translate(err, key.ErrNotFound)
	}

	return record.toDomain()
}

func (r realmKeyRepository) ListByRealm(
	ctx context.Context, realmID uuid.UUID, statuses []key.Status,
) ([]*key.Key, error) {
	query := r.db.WithContext(ctx).Where("realm_id = ?", realmID.String())

	if len(statuses) > 0 {
		wanted := make([]string, 0, len(statuses))
		for _, status := range statuses {
			wanted = append(wanted, status.String())
		}

		query = query.Where("status IN ?", wanted)
	}

	var records []realmKeyRecord

	// Ordered by id and not by created_at: the id is a UUIDv7, so this is
	// chronological on all four engines, while created_at is TEXT on SQLite
	// written as RFC 3339 with trailing zeros trimmed, where a value with no
	// fractional part sorts after one that has it.
	if err := query.Order("id DESC").Find(&records).Error; err != nil {
		return nil, translate(err, key.ErrNotFound)
	}

	return keysToDomain(records)
}

func (r realmKeyRepository) Update(ctx context.Context, k *key.Key) error {
	// A map and not a struct: the columns written are named here, so a field
	// added to the record later cannot start being written by this call.
	err := r.db.WithContext(ctx).
		Model(&realmKeyRecord{}).
		Where("id = ?", k.ID().String()).
		Updates(map[string]any{
			"status":        k.Status().String(),
			"active_marker": markerFor(k.Status()),
			"updated_at":    Timestamp(k.UpdatedAt()),
		}).Error

	return translate(err, key.ErrNotFound)
}

func (r realmKeyRepository) Rewrap(ctx context.Context, k *key.Key) error {
	err := r.db.WithContext(ctx).
		Model(&realmKeyRecord{}).
		Where("id = ?", k.ID().String()).
		Updates(map[string]any{
			"private_key": base64.StdEncoding.EncodeToString(k.Sealed()),
			"kek_id":      k.KEKID(),
			"updated_at":  Timestamp(k.UpdatedAt()),
		}).Error

	return translate(err, key.ErrNotFound)
}

func (r realmKeyRepository) ListStaleKEK(
	ctx context.Context, kekID string, limit int,
) ([]*key.Key, error) {
	var records []realmKeyRecord

	err := r.db.WithContext(ctx).
		Where("kek_id <> ?", kekID).
		Order("id").
		Limit(limit).
		Find(&records).Error
	if err != nil {
		return nil, translate(err, key.ErrNotFound)
	}

	return keysToDomain(records)
}

func keysToDomain(records []realmKeyRecord) ([]*key.Key, error) {
	found := make([]*key.Key, 0, len(records))

	for _, record := range records {
		built, err := record.toDomain()
		if err != nil {
			return nil, err
		}

		found = append(found, built)
	}

	return found, nil
}
```

```go
// create writes the realm and its signing keys together. A realm that exists
// and cannot sign is not a state anything should be able to observe — the same

func (s *RealmService) create(ctx context.Context, slug, displayName string) (*realm.Realm, error) {
	created, err := realm.New(slug, displayName, s.publicBaseURL)

	if err != nil {
		return nil, err
	}

	err = s.store.InTx(ctx, func(tx Store) error {
		if createErr := tx.Realms().Create(ctx, created); createErr != nil {
			return createErr
		}

		return s.keys.persist(ctx, tx, prepared)
	})
	if err != nil {

	}

	return created, nil
}
```

```go
func WriteBytes(w http.ResponseWriter, status int, contentType string, body []byte) {
```

```go
// Package oidc serves the protocol endpoints of a realm. It answers JSON, in
// the OAuth 2 error format the rest of the service already writes, and it never
// answers HTML: an HTML document is the wrong reply at a protocol endpoint.
package oidc

import (
	"context"
	"net/http"

	"github.com/google/uuid"
	"github.com/phuslu/log"
	"github.com/rootless-dev/aegis/internal/domain/key"
	"github.com/rootless-dev/aegis/internal/domain/realm"
)

// JWKSPath is the route under a realm. Identical to Keycloak's, so a client
// migrating with the url written down keeps working. `certs` is a misnomer
// inherited along with it: what is served is public keys.
const JWKSPath = "/protocol/openid-connect/certs"

// realmPattern is the segment the router binds the slug to. The pattern syntax
// belongs to the router, and this package neither imports it nor parses it —
// it only says which name it expects to read back through SlugFunc.
const realmPattern = "/{realm}"

// RealmResolver is the single door to a realm. It is an interface here because
// the consumer declares what it needs: this package requires one method of
// *service.RealmService, and the status rule that method applies.
type RealmResolver interface {
	Resolve(ctx context.Context, slug string) (*realm.Realm, error)
}

// KeyPublisher returns what belongs in the JWKS: active and passive keys, never
// disabled ones.
type KeyPublisher interface {
	Published(ctx context.Context, realmID uuid.UUID) ([]*key.Key, error)
}

// SlugFunc reads the realm slug the router matched. It is injected because the
// router is chi and only internal/application knows that — the same reason
// internal/http/assets declares a Router interface of its own instead of
// importing one.
type SlugFunc func(r *http.Request) string

// Router is the smallest surface this package needs from whatever mux the
// assembly built.
type Router interface {
	Get(pattern string, h http.HandlerFunc)
	Head(pattern string, h http.HandlerFunc)
}

type Handler struct {
	realms RealmResolver
	keys   KeyPublisher
	slug   SlugFunc
	logger *log.Logger
}

func New(realms RealmResolver, keys KeyPublisher, slug SlugFunc, logger *log.Logger) *Handler {
	return &Handler{realms: realms, keys: keys, slug: slug, logger: logger}
}

// Mount registers the routes of this surface. Every GET gets a HEAD beside it:
// the router matches by method, so the alternative is a 405 for a method the
// endpoint plainly supports.
func (h *Handler) Mount(router Router) {
	router.Get(realmPattern+JWKSPath, h.JWKS)
	router.Head(realmPattern+JWKSPath, h.JWKS)
}
```

```go
// jwksMediaType is what RFC 7517 registers. Keycloak answers application/json;
// every client library parses the body without inspecting the type, so the
// registered one is used even though the route above chose compatibility.
const jwksMediaType = "application/jwk-set+json"

// jwksMaxAge is what a well-behaved client honours. A client fetches the JWKS
// on start, on schedule, and in a burst the moment it meets an unknown kid —
// which is every client at once, right after a rotation.
const jwksMaxAge = "public, max-age=300"

type jwkSet struct {
	Keys []key.JWK `json:"keys"`

func (h *Handler) JWKS(w http.ResponseWriter, r *http.Request) {
	slug := h.slug(r)

	found, err := h.realms.Resolve(r.Context(), slug)
	if err != nil {
		// Unknown and archived answer alike. Telling a caller which realms
		// exist but are archived is information this endpoint has no reason to
		// publish.
		if errors.Is(err, realm.ErrNotFound) || errors.Is(err, realm.ErrNotAvailable) {
			response.WriteError(w, http.StatusNotFound, response.Error{
				Code:        response.ErrorInvalidRequest,
				Description: "no realm named " + slug,
			})

			return
		}

		h.logger.Error().Err(err).Str("realm", slug).Msg("resolving a realm for the jwks")
		response.WriteServerError(w)

		return
	}

	published, err := h.keys.Published(r.Context(), found.ID())
	if err != nil {
		h.logger.Error().Err(err).Str("realm", slug).Msg("reading the realm keys")
		response.WriteServerError(w)

		return
	}

	// A non-nil empty slice, so a realm whose keys are all disabled serves
	// {"keys":[]} rather than {"keys":null}.
	document := jwkSet{Keys: make([]key.JWK, 0, len(published))}

	for _, current := range published {
		jwk, jwkErr := current.JWK()
		if jwkErr != nil {
			h.logger.Error().Err(jwkErr).Str("realm", slug).Str("kid", current.KID()).
				Msg("projecting a key into a jwk")
			response.WriteServerError(w)

			return
		}

		document.Keys = append(document.Keys, jwk)
	}

	encoded, err := json.Marshal(document)
	if err != nil {
		h.logger.Error().Err(err).Str("realm", slug).Msg("encoding the jwks")
		response.WriteServerError(w)

		return
	}

	// Over the rendered bytes, which is why the repository orders by id: an
	// unstable order would produce a new ETag for an unchanged document.
	sum := sha256.Sum256(encoded)
	etag := `"` + base64.RawURLEncoding.EncodeToString(sum[:]) + `"`

	w.Header().Set("Cache-Control", jwksMaxAge)
	w.Header().Set("ETag", etag)

	if matches(r.Header.Get("If-None-Match"), etag) {
		w.WriteHeader(http.StatusNotModified)

		return
	}

	// Public, because the whole document is public keys.
	response.WriteBytes(w, http.StatusOK, jwksMediaType, encoded)
}

// matches implements the If-None-Match comparison of RFC 9110 section 13.1.2:
// a comma separated list, `*` matching anything, and the weak prefix ignored
// because this comparison is the weak one.
func matches(header, etag string) bool {
	if header == "" {
		return false
	}

	if strings.TrimSpace(header) == "*" {
		return true
	}

	for _, candidate := range strings.Split(header, ",") {
		if strings.TrimPrefix(strings.TrimSpace(candidate), "W/") == etag {
			return true
		}
	}

	return false
}
```

```go
func dispatchKey(args []string) ([]string, Runner, error) {
	if len(args) == 0 {
		return nil, nil, fmt.Errorf("aegisd: key needs a verb\n\n%s", usage)
	}

	case "list":

	}
}

func dispatchKeyRotate(args []string) ([]string, Runner, error) {

		return nil, nil, err

// requireArgument takes the next positional token. A leading dash means the
// argument is missing and the flags have started, which withoutStrayTokens
// cannot tell apart on its own.
func requireArgument(args []string, command, what string) (string, []string, error) {
	if len(args) == 0 || args[0] == "" || args[0][0] == '-' {
		return "", nil, fmt.Errorf("aegisd: %s needs %s\n\n%s", command, what, usage)
	}

	return args[0], args[1:], nil
}

// keyServices opens the database through the same translation the server uses,
// and builds the same services the server builds. Nothing here reimplements a
// rule: every verb below is one call.
func keyServices(cfg *configs.Application) (*service.RealmService, *service.KeyService, *database.DB, error) {
	db, _, err := open(cfg)
	if err != nil {
		return nil, nil, nil, err
	}

	current, err := cfg.Crypto.Bytes()
	if err != nil {
		return nil, nil, nil, err
	}

	previous, err := cfg.Crypto.PreviousBytes()
	if err != nil {
		return nil, nil, nil, err
	}

	keeper, err := sealer.New(current, previous)
	if err != nil {
		return nil, nil, nil, err
	}

	publicURL, err := url.Parse(cfg.PublicURL)
	if err != nil {
		return nil, nil, nil, err
	}

	store := repository.NewStore(db.Gorm)
	keys := service.NewKeyService(store, keeper, keygen.New())

	return service.NewRealmService(store, publicURL, keys), keys, db, nil
}

	cfg *configs.Application, slug, kid, outcome string,
	apply func(context.Context, *service.KeyService, uuid.UUID) error,
) int {
	realms, keys, db, err := keyServices(cfg)
	if err != nil {
		return fail(err)
	}

	defer func() { _ = db.Shutdown(context.Background()) }()

	ctx := context.Background()

	found, err := realms.FindBySlug(ctx, slug)
	if err != nil {
		return fail(realmError(slug, err))
	}

		if errors.Is(err, key.ErrInvalidTransition) {

			// obvious from the outside: an active key cannot be disabled,
			// because the realm would be left unable to sign.

					"which makes a new key active and this one passive",
				err, slug,
			))
		}

		return fail(err)
	}

	fmt.Printf("%s of realm %s is now %s\n", kid, slug, outcome)

	return 0
}

		return fail(err)
	}

	fmt.Printf("rewrapped %d keys; every key is now sealed under the current master key\n", moved)

	return 0
}
```

```go
func contains(values []string, wanted string) bool {
	for _, value := range values {
		if value == wanted {
			return true
		}
	}

	return false
}

func equalSets(first, second []string) bool {
	if len(first) != len(second) {
		return false
	}

	for _, value := range first {
		if !contains(second, value) {
			return false
		}
	}

	return true
}

// replaceEnv, removeEnv and valueOf operate on the NAME=value slice the
// harness builds. Write them here unless helpers_test.go already has
// equivalents — movedTo in schema_test.go is the same idea for AEGIS_PUBLIC_URL, and
// if it generalises, reuse it instead of adding a second mechanism.
func replaceEnv(env []string, name, value string) []string {
	out := append(removeEnv(env, name), name+"="+value)

	return out
}

func removeEnv(env []string, name string) []string {
	out := make([]string, 0, len(env))

	for _, entry := range env {
		if !strings.HasPrefix(entry, name+"=") {
			out = append(out, entry)
		}
	}

	return out
}

func valueOf(env []string, name string) string {
	for _, entry := range env {
		if strings.HasPrefix(entry, name+"=") {
			return strings.TrimPrefix(entry, name+"=")
		}
	}

	return ""
}
```

## What is deliberately not in this plan

- **Discovery.** No `/.well-known/openid-configuration`, no RFC 8414 document.
  They arrive with the endpoints they would advertise.
- **`default_signature_alg` on `realms`.** No consumer until something signs.
- **Automatic rotation and key expiry.** No place to configure a schedule until
  the admin API exists.
- **Encryption keys for JWE.** The `purpose` column holds the place.
- **Key import.** An admin API operation with its own validation surface.
- **A signer cache.** Slice 4, where there is something to measure and where the
  staleness a rotation on another replica causes must be answered.
- **Any HTTP surface for administering keys.** Slice 5 for the API, slice 6 for
  the console. The CLI here is the thin adapter both will replace at the edge
  while calling the same service.
